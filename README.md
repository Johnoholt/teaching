# teaching
Tools for teaching

My repository for developing teaching materials.  Enjoy.

## Canvas New Quiz Builder
- Builds new canvas quizzes from a given set of material.  Defaults to higher order thinking questions and auto-graded questions where applicable.
- Load the skill into your AI.  The simplest way is to download the zip file under Releases to the right.  Your AI will know what to do with it.
- Feed the AI the material for the quiz and call the skill to build a QTI.zip.
- Choose 'Import Existing Content' in Canvas, choose QTI.zip and be sure to select New Quiz when importing.
