# teaching
Tools for teaching

My repository for developing teaching materials.  Enjoy.

## Canvas New Quiz Builder
- Builds new canvas quizzes from a given set of material.  Defaults to higher order thinking questions and auto-graded questions where applicable.
- Load the skill into your AI.  Feed the AI the material for the quiz and call the skill to build a QTI.zip.
- Import Existing Content to Canvas, choose QTI.zip and be sure to select New Quiz when importing.
