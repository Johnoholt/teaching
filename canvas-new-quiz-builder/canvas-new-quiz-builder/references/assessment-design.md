## Design target

Build an assessment that measures meaningful learning rather than merely collecting isolated facts. Prioritize application, analysis, comparison, diagnosis, misconception repair, evaluation, and transfer while retaining automatic grading wherever a defensible key exists.

An item may be:

- Cognitively valuable but answerable from generic knowledge.
- Source-dependent but cognitively simple.
- Both cognitively valuable and source-dependent.
- Neither; normally discard these.

Use higher-value items for the core quiz. Include recall support or source checks only when they serve a deliberate instructional purpose.

## Source use

- Map each objective to specific source passages, timestamps, diagrams, examples, activities, or existing-bank items.
- Quote or closely paraphrase only the amount needed for a stimulus.
- Preserve enough context to make the keyed answer defensible.
- Use source-specific examples when they matter to the lesson; do not require students to memorize incidental phrasing.
- Preserve assessed webpage content in a stimulus when the page may change.
- If the source is too thin, contradictory, or ambiguous, flag the limitation instead of fabricating an item.
- When combining sources, identify conflicts and avoid presenting one disputed claim as uncontested fact.

## Auto-grading funnel

For each objective or required piece of evidence:

1. State what a successful response must demonstrate.
2. Decide whether the supplied material supports one defensible fixed key.
3. If yes, choose the strongest fitting auto-graded type: stimulus-linked selection, categorization, dropdown, matching, multiple answer, ordering, or multiple choice.
4. If no fixed key exists, use Essay for focused reasoning, judgment, explanation, reflection, or transfer.
5. Use File Upload only when the artifact itself must be inspected, such as a screenshot, interaction excerpt, log, spreadsheet, report, project file, or final product.

Do not ask students to explain an objectively checkable result in prose. Do not reduce authentic judgment, creativity, or evidence evaluation to a fake fixed-answer key.

In the blueprint, list for every manually graded item:

- Evidence being collected.
- Chosen question type.
- Point value.
- Brief reason a supported auto-graded type would not be valid.

Report automatically graded and manually graded item counts and point totals.

## Stimulus sets

Prefer a stimulus when two or more questions can use the same evidence without revealing one another. Strong stimuli include:

- A 100–300 word excerpt from an assigned reading or transcript.
- A screenshot, interface, chart, map, or course diagram.
- A short discipline-specific case.
- Two explanations, solutions, or responses to compare.
- A flawed explanation containing several diagnostic clues.
- A table that requires observation before interpretation.
- A worked example that students must critique, extend, or apply.

A strong three-item sequence often asks students to:

1. Identify or classify the relevant observation.
2. Distinguish interpretations, causes, evidence, or misconceptions.
3. Select or complete the best explanation, decision, or next action.

Do not make all child items restate the same inference. Do not put the answer to one child in another child's wording.

## Higher-order question construction

### Categorization

Use for scenarios, claims, evidence, errors, examples, or actions that fit non-overlapping concepts. Define categories on the same logical level. Every scored option must have one best category; a distractor must belong to none.

### Dropdown cloze

Use 2–5 linked blanks in a compact explanation. Each blank should test a meaningful relationship. Make all choices grammatically compatible. Prefer misconception repair, causal relationships, comparison, and procedural decisions over isolated vocabulary.

### Scenario-based multiple choice

Present a concrete situation and ask for the best interpretation, explanation, evidence, diagnosis, or next action. Distractors should represent plausible errors, incomplete reasoning, or misuse of the relevant concept.

### Multiple answer

Use when several claims, pieces of evidence, causes, or actions must be judged independently. Avoid disguised true/false lists with trivial wording. State the selection expectation clearly and verify Canvas scoring after import.

### Matching

Use for exact relationships such as scenario-to-concept, observation-to-explanation, evidence-to-claim, or error-to-correction. Do not use matching when several right-side answers could reasonably fit one prompt.

### Ordering

Use only when sequence or scale is the learning target: a procedure, causal chain, chronology, development, or clearly defined continuum. Because Canvas grades Ordering all-or-nothing, keep the list short enough that the scoring remains proportionate.

## Existing-bank conversion

For each original item:

1. Identify its purpose: recall, conceptual distinction, misconception, sequence, scale, cause and effect, observation and explanation, application, evaluation, or source check.
2. Keep it as multiple choice when it is already scenario-based, its distractors are strong, or it serves a deliberate low-stakes check.
3. Convert it when choices can become useful categories, linked dropdowns, matching pairs, evidence sets, or procedural steps.
4. Reuse wrong answers only when they represent real misconceptions or predictable errors.
5. Discard or rewrite grammatical giveaways, joke answers, ambiguous keys, unsupported trivia, and duplicative items.

Do not convert merely to increase the number of clicks. A transformed item should improve validity, cognitive engagement, or source use.

## Quiz-level design

- Cover objectives in proportion to importance, not source length.
- Use a strong majority of application, analysis, evaluation, transfer, conceptual distinction, and misconception-repair items.
- Avoid testing the same concept repeatedly under cosmetic wording changes.
- Use equivalent variants or item-bank-ready alternatives when requested.
- Randomize only when it does not break stimulus order, causal sequence, or fairness.
- Keep wording and visual complexity appropriate to the audience.
- Record a locator for every scored item so the instructor can audit it efficiently.
- Balance exact-match and partial-credit formats deliberately.

## Source checks

Reading or viewing verification can be a legitimate supporting objective. Use it honestly:

- Label the role `source_check`.
- Ask about a meaningful example, claim, sequence, visual, or distinction—not an arbitrary word or cosmetic detail.
- Prefer a detail connected to later understanding.
- Keep these occasional by default: usually 10–20% of scored items.
- Do not describe a simple source check as analysis or application.

## Manual-grading fallback

Use Essay or File Upload only after considering every supported auto-graded format. Manual questions should collect concise, inspectable evidence with clear expectations.

- Essay: focused reasoning, judgment, explanation, critique, reflection, or transfer.
- File Upload: screenshots, logs, spreadsheets, reports, design files, calculations, or final products that must be inspected.

Avoid generic prompts such as “What did you learn?” when a more focused request can identify the evidence the instructor needs.

## Final review

For each item ask:

- What objective does this measure?
- Does it require application, analysis, evaluation, transfer, or meaningful conceptual distinction?
- Is the answer grounded in the supplied material?
- Does an auto-graded type measure the evidence validly?
- What ambiguity or grading risk remains?

Report only material risks to the instructor.
